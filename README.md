# 🕌 مشروع مشكاة (Mishkat)

**مشكاة** هو تطبيق ويب إسلامي شامل ومتكامل، صُمم ليكون الرفيق الإيماني اليومي للمسلم. يوفر التطبيق واجهة عصرية وسهلة الاستخدام للوصول إلى القرآن الكريم تلاوةً وقراءةً، بالإضافة إلى الأذكار، مواقيت الصلاة، السنن، والقصص الإسلامية، مع دعم كامل للتشغيل في الخلفية والعمل دون اتصال بالإنترنت (PWA).

---

## ✨ المميزات الرئيسية

### 📖 القرآن الكريم (قراءة)
* تصفح المصحف الشريف بخط واضح ومريح للعين.
* إمكانية حفظ آخر صفحة تم الوصول إليها للرجوع إليها لاحقاً.
* دعم الوضعين الفاتح والداكن (Light/Dark Mode) لراحة العين أثناء القراءة.

### 🎧 الصوتيات والتلاوات (مُشغّل متطور)
* **مشغل صوتي عائم:** يستمر في العمل بسلاسة حتى عند التنقل بين صفحات التطبيق المختلفة.
* **دعم التشغيل في الخلفية:** متوافق مع نظام الوسائط (`MediaSession API`) للتحكم في الصوت (تشغيل، إيقاف، تقديم، تأخير، انتقال للسورة التالية) من شاشة القفل أو مركز الإشعارات.
* **التبديل التلقائي (Fallback CDN):** نظام ذكي يقوم بالتبديل إلى روابط صوت بديلة تلقائياً في حال فشل المصدر الأساسي لضمان عدم انقطاع التلاوة.
* **تعدد القراء:** مكتبة واسعة تضم أشهر القراء بروايات مختلفة.
* **قائمة المفضلات:** إمكانية حفظ السور المفضلة للوصول السريع إليها.

### 🤲 الأذكار والأدعية
* أذكار الصباح والمساء، أذكار النوم، والاستيقاظ، وغيرها من الأذكار اليومية.
* عدّاد إلكتروني مدمج مع الأذكار لتسهيل التسبيح.

### ⏰ مواقيت الصلاة
* عرض دقيق لمواقيت الصلاة بناءً على الموقع الجغرافي للمستخدم.
* تنبيهات واجهة بسيطة لمعرفة الصلاة القادمة والوقت المتبقي لها.

### 📚 مكتبة السنن والقصص الإسلامية
* **السنن النبوية:** قسم مخصص لإحياء السنن المهجورة والأحاديث النبوية الشريفة.
* **القصص:** مجموعة من قصص الأنبياء، الصحابة، والتابعين لأخذ العبرة والموعظة.

## 🛠️ التقنيات المستخدمة

تم بناء المشروع بالاعتماد على تقنيات الويب القياسية لضمان الخفة والسرعة وعدم الاعتماد على مكتبات خارجية ثقيلة:
* **الواجهة الأمامية:** HTML5, CSS3, Vanilla JavaScript (JS).
* **الخادم (Backend Proxy):** Node.js و Express.js لتجاوز قيود CORS وتسهيل تحميل الصوتيات.
* **تخزين البيانات:** الاعتماد على `localStorage` لحفظ التفضيلات (الوضع الداكن، المفضلات، القارئ المختار).
* **معمارية PWA:** التطبيق مجهز ليكون تطبيق ويب تقدمي (Progressive Web App) يمكن تثبيته على الهواتف والحواسيب.
